## Design encoded

Paper: 10 skin donors (breast or abdomen leftover tissue) and 5 peripheral-blood donors; ILC2 = CRTH2+; ILC3 = CRTH2− CD117+ NKp44−. Spreadsheet donor IDs 2–12 match that count (skin: 2,3,5–12; blood: 2–6) but the paper describes **independent** surgery vs Sanquin buffy-coat cohorts, not matched people. `characteristics[individual]` is namespaced `skin-{id}` / `blood-{id}`. Source names remain `donor_{id}_{skin|blood}_{ILC2|ILC3}` (assay labels from the deposit). DDA libraries use `pooled_1-12_{skin|blood}_ILC`.

DIA groups:

|---|---|---|
| 10 | skin | group 2 innate lymphoid cell (CL:0001069) |
| 10 | skin | group 3 innate lymphoid cell (CL:0001071) |
| 5 | peripheral blood | group 2 innate lymphoid cell |
| 5 | peripheral blood | group 3 innate lymphoid cell |

DDA libraries: pooled ILC2+ILC3 → parent `innate lymphoid cell` (CL:0001065). Spreadsheet `ILC2 and ILC3` is not a CL label.

## Disease and anatomy

Spreadsheet `healthy` → `normal` (PATO:0000461). Deposit `blood` → `peripheral blood` (BTO:0000553; paper: buffy coats / peripheral blood). Deposit `skin` kept as `skin` (BTO:0001253). Cells were isolated from dermis after epidermis removal; `dermis` was not used because the study and PRIDE fields describe skin ILCs and per-sample breast vs abdomen is not mapped.

`factor value[cell type]` and `factor value[organism part]` copy the corresponding characteristics (ILC2 vs ILC3; skin vs peripheral blood).

## Technical metadata

- Instrument: Q Exactive HF-X (`MS:1002877`) from paper Methods and the deposited spreadsheet. PRIDE structured `instruments` field says only `Q Exactive` (generic) and is overridden. File prefixes `QE8` / `QE9` are treated as two instruments of the same model.
- DIA: `NT=Data-independent acquisition;AC=PRIDE:0000450`. Confirmed in paper Methods (32 variable isolation windows 14.4–562.8 m/z; MS1 350 or 300 to 1650 m/z; stepped NCE 25 / 27.5 / 30) and in PRIDE `dataProcessingProtocol` (Spectronaut). Filenames contain `_DIA_`.
- DDA library: `NT=Data-dependent acquisition;AC=PRIDE:0000627`; top-15; NCE 27; isolation 1.4 m/z; MS1 300–1650 m/z.
- Label: `NT=label free sample;AC=MS:1002038`
- Digestion: trypsin (`MS:1001251`) and Lys-C (`MS:1001309`)
- Reduction DTT (`PRIDE:0000608`); alkylation iodoacetamide (`PRIDE:0000599`) → Carbamidomethyl C fixed (`UNIMOD:4`). Publisher HTML says “indole-3-acetic acid”; PRIDE protocol says IAA at 25 mM in the dark after DTT, which is iodoacetamide.
- Variable mods from MaxQuant search: Oxidation M (`UNIMOD:35`); Acetyl protein N-term (`UNIMOD:1`). Spectronaut DIA used software defaults; the same mods are kept because alkylation is chemical and the DDA search listed them.
- Dissociation: HCD as `NT=beam-type collision-induced dissociation;AC=MS:1000422`
- DIA windows: upper `1650`; lower `not available` (paper: 350 or 300); isolation width `not available` (variable windows)
- Precursor/fragment tolerances: `not available` (numeric MaxQuant / Spectronaut values not stated)
- Assay name = RAW file stem; DIA fraction identifier `1`; DDA fraction identifier 1–16 (skin) or 1–8 (blood); technical replicate 1; biological replicate 1 per DIA source, `pooled` for libraries
- Age, sex, ancestry: `not available` (not per donor; not invented from cohort text)
- Developmental stage: `adult` (EFO:0001272) on blood rows only (“healthy adult volunteers”); skin plastic-surgery donors not stated as adult-only → `not available`
- Material type: `cell`

Dropped unofficial spreadsheet columns: `characteristics[donor]` (moved to `characteristics[individual]` / source name), `characteristics[sample type]` (value “FACS ILC” is not a PRIDE sample-type child), `comment [method]` (encoded as acquisition method). Spreadsheet `healthy` and `Not relevant` fraction IDs were not copied.

## Gaps

- No per-donor age, sex, or ancestry
- Skin donor developmental stage not stated
- Spreadsheet pooled label is “pooled 1–12” but no individual `Donor_1` DIA RAW is deposited
- ILC3 isolation was NKp44-negative; parent `group 3 innate lymphoid cell` was used rather than `NKp44-negative group 3 innate lymphoid cell, human` (CL:0001080)
- DIA MS1 lower bound and isolation-window width not a single number
- Search mass tolerances not stated
- Raw-header instrument confirmation was not run (paper + spreadsheet already specify HF-X)
