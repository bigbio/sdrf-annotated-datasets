## Technical metadata

- Instrument: `timsTOF Pro` (`MS:1003005`); not `timsTOF Pro 2` (`MS:1003230`). PRIDE structured field, paper, and protocol agree.
- Acquisition: `NT=Data-independent acquisition;AC=PRIDE:0000450` (diaPASEF flavour; user/campaign rule). Deposited files are all `diaPASEF`/`DIA` in the name. ddaPASEF library runs were not deposited.
- Label: `NT=label free sample;AC=MS:1002038`
- Digestion: trypsin (`MS:1001251`) and Lys-C (`MS:1001309`); dual `comment[cleavage agent details]`. DIA FFPE workflow (paper + PRIDE): LysC 4 h then trypsin overnight. **No reduction/alkylation** on those wells, so Carbamidomethyl was **not** annotated. Library tissue (not in this RAW set) used DTT + chloroacetamide and 24-fraction concatenation.
- Spectronaut 12 “default settings” (except local normalisation) were used; numeric default PTMs/tolerances/windows are not stated. Collision energy, precursor/fragment tolerances, and DIA scan/isolation windows are `not available`.
- Dissociation: `NT=collision-induced dissociation;AC=MS:1000133` (timsTOF / PASEF; CID is the PSI-MS synonym). Not HCD.
- Assay name = deposited `.d` stem; fraction `1`; technical replicate `1`; biological replicate `1` per source.
- Ancestry: spreadsheet `Caucasian` → `European ancestry` (HANCESTRO:0005; exact synonym Caucasian). Paper: cohort “consists solely of individuals of Caucasian ethnicity.”
- Age: spreadsheet integers formatted `{n}Y` (range 31Y–84Y).
- Sex: `female` / `male` from the spreadsheet.
- Developmental stage: `adult` (all recorded ages ≥31Y; melanoma diagnostic cohort).
- Cell type: `melanocyte` (CL:0000148). Spreadsheet “melanoma cells” / “nevi cells” are not CL labels; PRIDE sample attributes and MART1-guided LMD support melanocyte.
- Material type: `tissue`
- `comment[sdrf annotation tool]`: `manual curation`

## Gaps

- DIA isolation windows / m/z range / collision energy not in the paper or PRIDE protocol.
- Spectronaut default variable mods not listed; FFPE DIA prep omitted alkylation, so UNIMOD:4 was not assumed.
- NAM biopsy site is only “Skin”; not refined beyond `zone of skin`.
- Spreadsheet `individual` reused numbers across cohorts; namespaced IDs are curator-assigned, not submitter IDs.
- MONDO:0005073 (`melanocytic nevus`) is an obsoletion candidate.
