# PXD000574

Sandbox: the iTRAQ set assignment and the fraction numbering are inferred from file dates. The iTRAQ modification the reviewer asked for is included.

## Why this is in sandbox
- Which `.wiff` belongs to which iTRAQ set is inferred from acquisition dates versus the dates in the two deposited `.group` file names. Those `.group` files were not decoded.
- Fraction identifiers follow the letter/number code in the file names and an assumed elution order.
- Technical-replicate order is therefore also uncertain.

## Return criteria
- A decoded sample sheet, or the `.group` files, that assigns each run to an iTRAQ set and an SCX fraction.
- Re-review, then move to `datasets/PXD000574/`.
