# PXD003531: author experiment design restores P/T sample and fraction links

Checked on 2026-09-29 against the [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD003531), all 59 deposited RAW names, the deposited [PRIMARY.zip](https://ftp.pride.ebi.ac.uk/pride/data/archive/2017/04/PXD003531/PRIMARY.zip), its `PRIMARY/ExpDesign.txt` and `PRIMARY/parameters.txt`, the [primary article](https://doi.org/10.1016/j.celrep.2017.03.015), and its [Table S1](https://ars.els-cdn.com/content/image/1-s2.0-S2211124717303327-mmc2.xlsx).

The experiment design has 32 primary-cell acquisitions and 27 OVCAR3 acquisitions in this deposit. `ExpDesign.txt` gives a `Paper` code and a fraction for every primary-cell RAW. The `P` files have fraction 1 and no phosphopeptide enrichment; the `T` files have fraction 3 and phosphorylated-peptide enrichment. The same `Paper` code links the P/T layers to one biological sample, while `EOC_1a`, `EOC_1b`, `EOC_2a`, `EOC_2b`, `EOC_4a` and `EOC_4b` explicitly distinguish the technical repeats. FTE codes 13–17 and OSE codes 26–29 are the five FTE and four OSE MS samples identified in the paper; the EOC codes identify four biological samples. The draft uses the base author code (`EOC_1`, `EOC_2`, `EOC_3`, `EOC_4`, `FTE_13`–`FTE_17`, `OSE_26`–`OSE_29`) as the source name, assigns the numeric biological replicate from that code, maps `a/b` to technical replicates 1/2, and records fractions 1 or 3.

This corrects the previous Sample 1–26 split, which treated the P/T layers as unrelated sources and set every fraction to 1. The deposited design contains 32 such primary-cell rows; the remaining 27 rows are OVCAR3 acquisitions. The two OVCAR3 treatment blocks retain their existing three biological replicates per treatment and the two acquisition batches. The paper's sample-preparation section directly supports sequential Lys-C and trypsin digestion, and `PRIMARY/parameters.txt` records MaxQuant 1.4.1.4, fixed carbamidomethylation and the deposited search settings.

## Local validation

The revised draft covers all 59 RAW files exactly once. `sdrf_review.py` reports no ragged rows, coordinate collisions or vendor/file contradictions; `validate-sdrf` reports only the existing offline ontology warnings and the descriptive no-factor advisory. The direct PRIDE record reconciliation remains scoped to the structured project record and does not override the file-level experiment design. It reports one `cleavage_agent_unsupported` blocker for Lys-C because that JSON record never names Lys-C; the article methods explicitly support sequential Lys-C followed by trypsin, so both article-backed cleavage agents remain annotated.
