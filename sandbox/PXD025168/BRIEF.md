# PXD025168：莱茵衣藻三重二甲基标记实验

- [原论文](https://doi.org/10.1111/tpj.15555)的实验设计与方法说明：异养、混合营养、光合自养三种条件进行轻、中、重三重二甲基标记，第三个生物学重复交换了标记。
- 当前草稿为 78 个 RAW × 3 行，共 234 行，但所有行的 `comment[label]` 都是同一个 `DIMETHYL 3PLEX`，未区分轻、中、重通道。修饰列又在所有重复中固定采用同一套条件—标签对应关系，与论文的第三重复交换标记不一致。不能把这些标签对应当成已核实的数据。
- 草稿的 `exp_I`、`exp_II`、生物学重复编号与具体 RAW 的关系尚未获得可核对的作者文件；不得猜测标签交换顺序。
- 数据存放于 [jPOST JPST001115](https://repository.jpostdb.org/entry/JPST001115)。本次公开目录读取未取得可用文件清单，PRIDE API 不提供该项目的实际归档文件。未完成 RAW 清单核验。
